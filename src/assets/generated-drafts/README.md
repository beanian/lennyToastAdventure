# Generated Drafts

Use this folder for raw Codex/image-generation drafts and rejected variants.

Do not reference files from this folder in `src/assets/manifest.js`. Promote reviewed assets into `src/assets/sprites`, `src/assets/ui`, `src/assets/backgrounds`, or `src/assets/effects` first.

See `docs/ASSET_PIPELINE.md` for prompt packs, review criteria, naming conventions, and promotion steps.
